# MODONSTORE — النسخة الاحترافية

متجر إلكتروني عربي متجاوب مع الهاتف والكمبيوتر، مبني بـ Node.js وExpress، وفيه:
- صفحة عرض المنتجات والبحث والتصنيف والترتيب.
- سلة مشتريات وحساب المجموع.
- نموذج طلب فيه الاسم والهاتف والمدينة والعنوان.
- تسجيل الطلب في الخادم، ثم فتح واتساب برسالة جاهزة لتأكيد الطلب.
- الأداء عند الاستلام (COD).
- لوحة إدارة على `/admin` لإضافة المنتجات وتعديلها وحذفها ورفع الصور.
- إدارة الطلبات وتحديث حالتها: جديد، تم التأكيد، قيد التوصيل، مكتمل، ملغي.
- مخزون بسيط يُنقص عند تسجيل الطلب ويُرجع عند إلغائه.

## 1) تشغيل الموقع على الكمبيوتر

1. ثبّت **Node.js 20 أو أحدث** من الموقع الرسمي: https://nodejs.org/
2. فك الضغط عن `MODONSTORE_PRO_COMPLETE.zip`.
3. افتح مجلد `MODONSTORE_PRO_COMPLETE`.
4. انسخ `.env.example` وسمّ النسخة `.env`.
5. افتح `.env` ببرنامج المفكرة وبدّل:
   - `ADMIN_USERNAME` باسم المستخدم اللي بغيتي.
   - `ADMIN_PASSWORD` بكلمة سر طويلة وفريدة.
   - `SESSION_SECRET` بنص عشوائي طويل، مختلف عن كلمة السر.
   - رقم واتساب مكتوب دولياً بالأرقام فقط. الرقم الحالي هو `212654283265` (أي 0654283265).
6. افتح Terminal / Command Prompt داخل المجلد وشغّل:
   ```bash
   npm install
   npm start
   ```
7. افتح المتصفح على: http://localhost:3000
8. لوحة الإدارة: http://localhost:3000/admin

**مهم:** ما ترفعش ملف `.env` للإنترنت أو تشاركو مع أي شخص.

## 2) كيفاش تزيد السلع

1. دخل إلى `/admin` وسجّل الدخول بالمعلومات اللي وضعتها في `.env`.
2. اختار «منتج جديد».
3. عمر اسم المنتج، الصنف، الثمن، الثمن القديم إذا كاين تخفيض، المخزون، الوصف والصورة.
4. اضغط «حفظ المنتج». غادي يبان المنتج فواجهة المتجر.
5. تقدر تعدّل أو تحذف أي منتج من نفس لوحة التحكم.

## 3) كيفاش كيشري الزبون

1. يختار المنتجات ويزيدها للسلة.
2. يضغط «إتمام الطلب» ويعمر الاسم والهاتف والمدينة والعنوان.
3. الخادم كيتحقق من المخزون وكيحفظ الطلب.
4. كيتفتح واتساب برسالة فيها رقم الطلب وتفاصيل المنتجات. خاص الزبون يضغط إرسال فواتساب بنفسه؛ فتح واتساب بوحدو ما كيعنيش أن الرسالة تسيفطات.
5. الطلب كيبان فلوحة الإدارة. تقدر تحدّث الحالة وتتواصل مع الزبون.
6. الأداء عند الاستلام، والتوصيل متاح لجميع مدن المغرب من حيث إعداد الموقع؛ خاصك أنت تتفق مع شركة توصيل وتحدد أثمنة وآجال التوصيل حسب المدن.

## 4) نشر الموقع على الإنترنت

هاد المشروع يحتاج **استضافة تدعم Node.js**. ما يكفيش ترفع ملفات HTML فقط، لأن لوحة الإدارة والطلبات كتحتاج الخادم.

قبل اختيار الاستضافة، تأكد من:
- تدعم Node.js 20+ وتشغيل `npm start`.
- عندها تخزين دائم (Persistent Disk/Volume) لملف `data/db.json` ومجلد `public/uploads`، لأنهما يحتويان على المنتجات والصور والطلبات.
- توفر HTTPS.
- تضبط متغيرات البيئة من لوحة الاستضافة: `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `SESSION_SECRET`, `STORE_WHATSAPP`, `NODE_ENV=production`, و`PORT` حسب تعليمات المنصة.
- النسخ الاحتياطي المنتظم لملف `data/db.json` والصور.

الخطوات العامة:
1. ارفع مجلد المشروع إلى GitHub بدون `.env` أو `data/db.json` أو بيانات الزبناء.
2. أنشئ Web Service على منصة استضافة تدعم Node.js واربطه بالمستودع.
3. أمر البناء: `npm install`، وأمر التشغيل: `npm start`.
4. أضف متغيرات البيئة من لوحة الاستضافة، واختر تخزيناً دائماً.
5. اربط الدومين ديالك وفعّل HTTPS.
6. جرّب طلباً تجريبياً، ثم تأكد من ظهوره في `/admin`.

## 5) حدود النسخة الحالية — مهم

- **لا يوجد بوابة أداء إلكتروني**. الأداء المتاح في هذه النسخة هو الدفع عند الاستلام فقط.
- الطلب يُحفظ في الموقع قبل فتح واتساب، لكن رسالة واتساب لا تُرسل تلقائياً؛ الزبون خاصه يضغط إرسال. إذا ما عندوش واتساب أو ما أرسلش الرسالة، يبقى الطلب محفوظاً في لوحة الإدارة.
- رقم الطلب والمنتجات والمخزون محفوظة في ملف JSON. هذا مناسب لتجربة متجر صغير، لكنه ليس قاعدة بيانات قوية للضغط العالي أو عدة عمليات متزامنة. لمتجر إنتاجي كبير، استعمل PostgreSQL أو MySQL ومعالجة معاملات للطلبات والمخزون.
- خاصك تحدد مصاريف التوصيل فعلياً وتتفق مع شركة توصيل. حالياً المجموع يعرض ثمن المنتجات فقط، ومصاريف التوصيل تُتفق مع الزبون قبل الإرسال.
- التخزين على بعض الاستضافات يكون مؤقتاً؛ إذا ما كانش التخزين دائماً، ممكن تضيع المنتجات والطلبات والصور بعد إعادة التشغيل أو النشر.
- لوحة الإدارة محمية بتسجيل الدخول، لكن قبل الإطلاق التجاري يُنصح بإضافة حماية أقوى من محاولات التخمين، نسخ احتياطية، وسياسة خصوصية وشروط بيع مناسبة.
- أضف صور المنتجات الحقيقية والأثمنة الدقيقة ومعلومات التوصيل والإرجاع قبل نشر المتجر للزبناء.

## 6) ملفات المشروع

- `server.js`: الخادم وواجهات المنتجات والطلبات والإدارة.
- `public/index.html`: واجهة المتجر.
- `public/admin.html`: لوحة الإدارة.
- `public/css/`: تنسيق الواجهات.
- `public/js/`: منطق السلة والشراء والإدارة.
- `data/db.json`: بيانات المنتجات والطلبات.
- `public/uploads/`: الصور التي ترفعها من لوحة الإدارة.
- `assets/product-watch.png`: صورة افتراضية للمنتج التجريبي.

هذه نسخة مشروع جاهزة للتشغيل بعد إعداد Node.js وملف `.env`، لكنها ليست مستضافة على الإنترنت تلقائياً.
